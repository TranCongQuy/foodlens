## 1. Academic Statement & Verification Methodology

Every entry below records an actual interaction with generative AI tools during the architectural planning, interface construction, security hardening, and evaluation of **DrawToStory**. In accordance with academic honesty standards:

## 3. Summary of Compliance with Academic Guidelines

1. **Diverse Types of AI Usage ($\ge 3$ types):**
   - *Code Generation & Scaffolding*: Creation of UI Primitives, Web Audio API synthesizers, and Edge Functions.
   - *Security Audit & Threat Modeling*: Zero-Trust review, elimination of client-side API keys, salted PIN hashing, and RLS inspection.
   - *Automated Testing & Quality Gate*: Generation of 6 image fixtures, contrast verification scripts, and pipeline regression tests.
   - *Design System Architecture*: Modern Storybook tokens, WCAG AA compliance, and Screen Wake Lock integration.
2. **Human Rejection / Override Cases ($\ge 1$ case):**
   - *Case 1 (Contrast)*: Rejected AI's proposed green color `#1F8A5B` (3.8:1 contrast) and mandated `#166E48` (5.49:1) to satisfy WCAG 2.1 AA.
   - *Case 2 (Storage)*: Rejected AI's proposal of public storage buckets for children's drawings; enforced signed URLs with 1-hour expiration.
   - *Case 3 (Secrets)*: Rejected storing `GEMINI_API_KEY` in the database or client environment; enforced 100% server-side isolation in Edge Function Secrets.
3. **Bug Finding and Fixing Cases ($\ge 1$ case):**
   - *Case 1*: Detected and fixed plain-text parental PIN exposure in client DOM and registration inputs.
   - *Case 2*: Fixed the `"Bé Bé Hà"` double-prefix string concatenation bug in `formatChildName`.
   - *Case 3*: Fixed duplicate-page rendering in `react-pageflip` by isolating per-page sentence and zoom regions.
   - *Case 4*: Resolved unrestricted access on 3 analytical views by introducing `security_invoker = true`.
4. **Combining Multiple AI Suggestions ($\ge 1$ case):**
   - Combined Laplacian variance blur detection with mean luminance analysis on client HTML5 canvas to filter unusable photos before triggering server-side Gemini API calls.
